## 🌟 What's This All About?

SeattleDoge is a visual love letter to the Emerald City, combining the internet's favorite meme dog with Seattle's iconic vibe. It's a 5-page interactive web experience featuring a Tokyo Night design system, dynamic topographic patterns, smooth gradients, and 5 hidden easter eggs to discover.

### ✨ Features That Actually Slap
- 🎨 **Tokyo Night Design System**: SVG topographic background, ambient orbs, Syne & Space Grotesk typography
- 📄 **5 Interactive Pages**: Landing → Doge Found → The City → The Vibes → Roadmap
- 🥚 **5 Hidden Easter Eggs**: Console art, title click, coffee counter, Konami code, patience timer
- 📱 **Fully Responsive**: Looks fire on everything from your phone to your ultrawide monitor
- ♿ **Accessible**: Skip-to-content, ARIA live regions, focus styles, prefers-reduced-motion
- ⚡ **Lightning Fast**: Pure vanilla HTML/CSS/JS, font preconnect, lazy loading

## 🚀 Quick Start

```bash
# Clone this beauty
git clone https://github.com/Manaiakalani/SeattleDoge.git
cd SeattleDoge

# Serve locally (any of these work)
python -m http.server 8000
npx serve -s .
# Or just open index.html in your browser 🤷‍♀️
```

## 🛠️ Tech Stack

- **Frontend**: Vanilla HTML5, CSS3, JavaScript (no build step, no frameworks)
- **Design**: Tokyo Night palette, CSS gradients, SVG topographic patterns
- **Typography**: Syne (headings), Space Grotesk (body), Comic Neue (doge bubbles)
- **Animations**: CSS keyframes + IntersectionObserver for scroll-triggered effects
- **Analytics**: Self-hosted privacy-friendly analytics

## 🎮 Easter Egg Hints

There are **5 easter eggs** hidden throughout the site. Each one unlocks a new page:

| # | Hint | Unlocks |

| 4 | 🎮 ↑↑↓↓←→←→BA | The Vibes |
| 5 | ⏰ Just wait around... | Roadmap |

## 🎨 The Aesthetic

- **Tokyo Night Palette**: Deep navy (#1a1b26), slate blues (#6b8cce), coral (#f47f78), gold (#f5d547)
- **SVG Topography**: Repeating contour line pattern as a fixed background
- **Ambient Orbs**: Blurred color circles for depth
- **Gradient Text**: Each page has unique gradient headings
- **Card System**: Frosted glass cards with hover glow and tag pills
